# 🛒 سمسار السودان

منصة بيع وشراء وإيجار السيارات والعقارات في السودان، مع نظام مفاصلة (تفاوض) مباشر بين البائع والمشتري داخل التطبيق.

## المزايا

- تصفح إعلانات السيارات والعقارات مع فلاتر حسب الفئة (سيارات/عقارات) ونوع المعاملة (بيع/إيجار).
- نشر إعلان بالصور (حتى 8 صور) وفيديو قصير اختياري، مع حقول خاصة بكل فئة.
- تسجيل دخول بسيط بالاسم ورقم الهاتف السوداني فقط (بدون كلمة سر أو OTP في هذه المرحلة).
- محادثة مباشرة بين المشتري والبائع لكل إعلان:
  - رسائل نصية عادية.
  - فقاعات "عرض سعر 💰" — أي طرف يقدر يرسل عرض/عرض مضاد بلا حدود.
  - زر "قبول هذا العرض ✅" يقفل الإعلان تلقائياً كـ "متفق عليه" ويخرجه من نتائج البحث العامة.
  - رسائل صوتية (تسجيل من المتصفح مباشرة، تُرفع لـ Supabase Storage).
  - زر اتصال هاتفي مباشر (tel:) كبديل خفيف عن المكالمات المباشرة داخل التطبيق.
- صفحة "إعلاناتي" للبائع وصفحة "محادثاتي" لمتابعة كل المفاصلات الجارية.
- تحديثات فورية (Realtime) عبر Supabase لكل من قائمة الإعلانات والمحادثات.

## الإعداد

### 1. تثبيت الحزم

```bash
npm install
```

### 2. إعداد Supabase

1. أنشئ مشروع جديد في [supabase.com](https://supabase.com) (أو استخدم مشروعاً موجوداً).
2. اذهب لـ **SQL Editor** وشغّل محتوى الملف `supabase/schema.sql` بالكامل مرة واحدة.
   - هذا الملف ينشئ كل الجداول (`users`, `listings`, `listing_media`, `conversations`, `messages`)، يفعّل Realtime، يضبط سياسات RLS، وينشئ Storage bucket باسم `media` لحفظ الصور/الفيديو/الرسائل الصوتية.
3. من **Project Settings > API** انسخ:
   - `Project URL` → `NEXT_PUBLIC_SUPABASE_URL`
   - `anon public key` → `NEXT_PUBLIC_SUPABASE_ANON_KEY`
4. انسخ `.env.local.example` إلى `.env.local` واملأ القيمتين.

### 3. التشغيل محلياً

```bash
npm run dev
```

### 4. النشر (Vercel مثلاً)

- اربط المشروع بـ Vercel (أو أي منصة Next.js أخرى).
- **مهم:** أضف نفس متغيرات البيئة (`NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`) في إعدادات المشروع على المنصة قبل النشر — وإلا سيعمل التطبيق بـ"وضع المعاينة" فقط (بدون قاعدة بيانات فعلية).

## بنية المشروع

```
src/
  app/
    page.tsx            صفحة تصفح الإعلانات (الرئيسية)
    new/page.tsx         نشر إعلان جديد
    listing/[id]/page.tsx تفاصيل إعلان
    chat/[id]/page.tsx    المحادثة والمفاصلة
    chats/page.tsx        قائمة محادثاتي
    my/page.tsx           إعلاناتي
  components/
    Header.tsx
    ListingCard.tsx
    PhoneGate.tsx         بوابة دخول بالاسم ورقم الهاتف
    VoiceRecorder.tsx     تسجيل الرسائل الصوتية
  lib/
    supabase.ts           عميل Supabase (مع وضع معاينة آمن بدون متغيرات بيئة)
    format.ts              أدوات الهاتف السوداني + تنسيق الأسعار والوقت
    session.ts              جلسة المستخدم البسيطة (localStorage)
    types.ts                أنواع TypeScript المشتركة
supabase/
  schema.sql               مخطط قاعدة البيانات الكامل (يُنفَّذ مرة واحدة)
```

## غير مشمول حالياً (يمكن إضافته لاحقاً)

- مكالمات صوتية/فيديو مباشرة (WebRTC) داخل التطبيق — تم الاستعاضة عنها بزر اتصال هاتفي مباشر بناءً على طلب صريح.
- تحقق OTP فعلي عبر SMS عند تسجيل الدخول (حالياً الاسم ورقم الهاتف يُحفظان مباشرة بدون تحقق).
- لوحة تحكم إدارية (Admin) لمراقبة الإعلانات والمحادثات.
