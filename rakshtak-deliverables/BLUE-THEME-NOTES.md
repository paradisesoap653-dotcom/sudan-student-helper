# ركشتك — الثيم الأزرق السماوي المتدرج (خلفيات فقط)

> تحويل الخلفية الداكنة الأصلية (رمادي/أسود) إلى تدرّج أزرق سماوي فاتح
> نسبياً (Sky Blue)، مع الإبقاء على كل الألوان الوظيفية كما هي (الكهرماني/
> البرتقالي كلون العلامة الأساسي للأزرار والحالات، الأخضر للنجاح، الأحمر
> للتحذير).

## تاريخ التكرارات

1. **المحاولة الأولى:** أزرق داكن جداً (قريب من الأسود) — طلب المستخدم تفتيحه.
2. **المحاولة الحالية (هذه):** أزرق سماوي أفتح ووضوحاً (Sky/Cyan-ish) —
   تدرّج من `#082f49` (الأعلى) إلى `#0369a1` (الأسفل)، بدل التدرّج القديم
   من `#050b1a` إلى `#102a52`.

## ما تغيّر بالضبط (نفس الملفات الثمانية من قبل)

| الملف | التغيير |
| --- | --- |
| `src/app/page.tsx` (صفحة الراكب) | التدرّج والبطاقات والحدود سماوية بدل الأزرق الداكن |
| `src/app/driver/page.tsx` (لوحة السائق) | نفس المعالجة |
| `src/app/admin/page.tsx` (لوحة الأدمن) | نفس المعالجة |
| `src/components/AdminGate.tsx` | نفس المعالجة (شاشة قفل الأدمن) |
| `src/components/Map.tsx` | خلفية إطار الخريطة وشارات المعلومات فوقها سماوية |
| `src/app/globals.css` | ثيم بلاطات Leaflet وأزرار التحكم بالخريطة سماوية |
| `src/app/layout.tsx` | `themeColor` أصبح `#0c4a6e` |
| `public/manifest.json` | `background_color`/`theme_color` سماويان |

## ما لم يتغيّر

- كل منطق الأعمال، مسارات `/api`، Supabase، OTP، RLS — كما هي بالضبط من المرحلة 3.
- لون العلامة الأساسي (الكهرماني/البرتقالي `#f5a70a` وأزرار `amber-500`).
- ألوان الحالة (أخضر النجاح، أحمر التحذير، والشارة الزرقاء لحالة "مكتملة").
- شعار `public/icon.png` (التوك توك الأصفر).

## التحقق

```bash
cd rakshtak
npm install
npm run typecheck   # 0 أخطاء
npm run build       # نجاح كامل — نفس عدد المسارات
```
