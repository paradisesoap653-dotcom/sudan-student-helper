# ركشتك — الثيم الأزرق المتدرج (خلفيات فقط)

> تحويل الخلفية الداكنة الحالية (رمادي/أسود) إلى تدرّج أزرق داكن، مع الإبقاء
> على كل الألوان الوظيفية كما هي (الكهرماني/البرتقالي كلون العلامة الأساسي
> للأزرار والحالات، الأخضر للنجاح، الأحمر للتحذير).

## ما تغيّر بالضبط

**فقط الملفات المتعلقة بألوان الواجهة** — لا شيء في المنطق أو الاتصال
بالخادم أو قاعدة البيانات:

| الملف | التغيير |
| --- | --- |
| `src/app/page.tsx` (صفحة الراكب) | الخلفية الرئيسية أصبحت تدرّج أزرق `from-[#050b1a] via-[#0a1830] to-[#102a52]`، وخلفيات الحقول/البطاقات الداخلية بدرجات أزرق داكن (`#0b1830`, `#0f2347`)، وحدود العناصر بدرجات أزرق (`border-blue-900/…`, `border-blue-950/…`) بدل الرمادي |
| `src/app/driver/page.tsx` (لوحة السائق) | نفس المعالجة أعلاه |
| `src/app/admin/page.tsx` (لوحة الأدمن) | نفس المعالجة أعلاه |
| `src/components/AdminGate.tsx` | نفس المعالجة أعلاه (شاشة قفل الأدمن) |
| `src/components/Map.tsx` | خلفية إطار الخريطة وشارات المعلومات فوقها بنفس درجات الأزرق |
| `src/app/globals.css` | ثيم بلاطات Leaflet وأزرار التحكم بالخريطة تحوّلت لدرجات أزرق (بدل الرمادي الداكن) |
| `src/app/layout.tsx` | `themeColor` (شريط المتصفح العلوي على الجوال) أصبح `#0a1830` |
| `public/manifest.json` | `background_color`/`theme_color` لتطبيق PWA أصبحا أزرق داكن |

## ما لم يتغيّر

- كل منطق الأعمال، مسارات `/api`، Supabase، OTP، RLS — كما هي بالضبط من المرحلة 3.
- لون العلامة الأساسي (الكهرماني/البرتقالي `#f5a70a` وأزرار `amber-500`) بقي كما هو — هو هوية «ركشتك» البصرية.
- ألوان الحالة (أخضر النجاح، أحمر التحذير) كما هي.
- شعار `public/icon.png` (التوك توك الأصفر) كما هو.

## التحقق

```bash
cd rakshtak
npm install
npm run typecheck   # 0 أخطاء
npm run build       # نجاح كامل — نفس عدد المسارات
```

## الملفات

- `zips/rakshtak-blue-theme-files.zip` — الشجرة الكاملة لمجلد `rakshtak/` بعد
  تطبيق الثيم الأزرق (بدون `node_modules` و`.next`)، جاهزة للتحميل المباشر
  من داخل المستودع.
