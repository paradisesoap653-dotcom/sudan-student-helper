# 🤖 وكيل النشر الآلي للاعلانات على مواقع التواصل
جاهز للعمل فورا بعد اضافة مفتاح البافر.

## خطوات التشغيل:
1.  من هذه المجلد شغل الامر لتثبيت المكتبات:
    ```bash
    npm install
    ```
2.  انسخ ملف `.env.example` الى `.env`:
    ```bash
    cp .env.example .env
    ```
3.  افتح ملف `.env` واستبدل `your-token-here` بالمفتاح الذي نسخته من موقع Buffer
4.  شغل الامر التالي لتتأكد من ان الوكيل يتعرف على حساباتك المتصلة:
    ```bash
    npm run list-channels
    ```
    لو ظهرت لك كل القنوات (فيسبوك، انستغرام، تيك توك) فكل شي جاهز.
5.  لنشر اول بوست تجريبي بعد 5 دقائق تلقائيا على جميع المنصات:
    ```bash
    npm run publish
    ```

## ماذا يفعل الوكيل حاليا:
✅ ينشر نفس البوست (الصورة والكابشن الجاهز) على جميع المنصات المتصلة
✅ يقوم بالنشر بعد 5 دقائق من تشغيل الامر كي تتمكن من مراجعته اذا اردت
✅ يخبرك في حال فشل النشر على اي منصة

## الميزات القادمة التي سنضيفها قريبا:
- ينشئ تصميمات البوستات تلقائيا بالذكاء الاصطناعي لاي تطبيق تعطيه اسمه ومميزاته
- يكتب سكربتات الريلز ويصدر التعليق الصوتي تلقائيا
- يجدول المنشورات على مدار الشهر كاملا في الاوقات المثالية التي يقترحها بافر
- يجلب لك الاحصائيات كل اسبوع ويوضح اي المنشورات حصلت على اكبر تفاعل.
